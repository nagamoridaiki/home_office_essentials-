# Home Office Essentials

## 技術スタック

- **Frontend**: Next.js 16 / React 19 / TypeScript / Tailwind CSS 4
- **Backend**: Go 1.27（標準ライブラリ `net/http`）
- **パッケージマネージャ**: pnpm 11（ワークスペース）

## 開発サーバーの起動

```bash
pnpm dev
```

次の 2 つが同時に立ち上がります。

- Frontend: http://localhost:3000
- Backend: http://localhost:8080
